# Public Data Only

This repository is public. It must never become a channel for anyone's confidential data.

## Rules

1. Every rating in `examples/**` carries `provenance:` naming a **public** source (reference design
   document ID, standard clause, vendor public datasheet, peer-reviewed paper) or the literal word
   `assumed`.
2. Never add values, configurations or drawings from an employer, a client, an interviewee, a
   vendor NDA, or a course's non-public material — even "anonymised". If in doubt, use `assumed`
   and a round number.
3. No customer names, site names, addresses, or utility account details.
4. Interview notes and sales material live outside this repository.
5. Rule packs that encode a company's private standards do not belong here; the public repo ships
   only generic, standard-derived checks.

Adding a new data source to `examples/` is a hard gate (`AGENTS.md`): ask the owner first.
